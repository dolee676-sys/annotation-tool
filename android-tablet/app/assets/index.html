回答方式

平板默认已与电脑端一致

词条按「词义 → 在当前语境 → 作用」回答；整段文字自动改为概括；选中问题先给答案。平板版固定中文，不含本机 Ollama。

悬浮取词

开启后，在 OneNote 等应用里选中文字，旁边会出现「注 / 问」小条。读取你主动选中或刚复制的文字；用「划」/整页抓取时，会把选区截图或页面文字发给你配置的模型服务商识别。不点注解不会保存。

未开启

长按「划」关闭后，不用去系统设置，点上面的「开启划」即可恢复。

部分系统（如 ColorOS）若开关是灰的，先去「应用信息」里允许受限设置。

OneNote 里点屏幕边缘的「划」→ 在原文上拖选文字 → 松手识别；长按「划」可整页抓取、读剪贴板或关闭。复制文字后也会自动出现「注 / 问」。

数据

历史、收藏、用量和 Key 只保存在这台平板，不会上传到除模型服务商以外的地方。Key 默认经系统 Keystore 加密后存放；若系统 Keystore 不可用会退化为明文保存。旧版本明文数据会在下次保存时自动加密。

「划」拖选只发送选区截图；「整页抓取」会发送整屏截图或页面文字给当前模型识别。两者都需要你主动触发。
